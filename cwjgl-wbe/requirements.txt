# ============================================================================

## 📦 项目信息

项目名: cwjgl-wbe (蔡文姬企业管理系统 - Web Backend & Frontend)
版本: 1.0.0
类型: ES Module (type: "module")
私有项目: true

## 🔧 系统环境要求

最低版本要求:
- Node.js >= 16.0
- npm >= 7.0

推荐版本:
- Node.js 18.x (LTS)
- npm 9.x 或 yarn 4.x
- Git >= 2.30

## 📋 npm 脚本命令

### 开发命令
npm run dev              # 启动前端开发服务器 (Vite) - 监听 localhost:5173
npm run server          # 启动后端 Express 服务器 - 监听 localhost:3000
npm run server:dev      # 开发模式启动后端 (同上)

### 构建命令
npm run build           # 生产环境构建 - 输出到 dist/ 目录
npm run preview         # 预览生产构建结果

### 数据库命令
npm run db:init         # 初始化 SQLite 数据库 (运行 init-db.cjs 脚本)
npm run db:reset        # 重置数据库 (删除 chat.db 后重新初始化)

### 代码质量命令
npm run lint            # ESLint 检查并自动修复代码
npm run format          # Prettier 格式化 src/ 目录
npm run test            # 测试模式 (vite --mode test)

## 📦 生产依赖 (dependencies)

### 前端框架和 UI
- vue@^3.5.13
  └─ 渐进式 JavaScript 框架，用于构建交互式用户界面
  └─ 版本: ^3.5.13 (最新 3.x，允许小补丁更新)

- vue-router@^4.5.0
  └─ Vue 官方路由管理器，处理应用的页面导航
  └─ 版本: ^4.5.0

- element-plus@^2.9.7
  └─ 企业级 UI 组件库（Vue 3），提供按钮、表单、对话框等组件
  └─ 版本: ^2.9.7

- @element-plus/icons-vue@^2.3.1
  └─ Element Plus 官方图标库

### 状态管理
- pinia@^3.0.1
  └─ Vue 3 的官方状态管理库，用于全局状态共享 (stores/)
  └─ 替代了 Vuex，API 更简洁

### HTTP 和网络
- axios@^1.13.6
  └─ Promise 基础的 HTTP 客户端库
  └─ 用于前端请求 API 和客户端与后端通信
  └─ 支持拦截器、超时、请求取消等功能

- cors@^2.8.6
  └─ Express 中间件，处理跨域资源共享 (CORS)
  └─ 让后端可以接受来自不同域的请求

### 后端框架
- express@^5.2.1
  └─ 轻量级 Web 框架 (Node.js 原生)
  └─ 处理 HTTP 路由、中间件、请求响应等
  └─ 本项目在 server.js 中使用

### 数据库 (后端)
- sqlite3@^6.0.1
  └─ SQLite 数据库驱动 (Node.js binding)

### 其他前端库

## 🔄 版本和更新策略

### 版本号含义
- ^x.y.z = 允许小版本和补丁版本更新 (>= x.y.z, < (x+1).0.0)
- ~x.y.z = 仅允许补丁版本更新 (>= x.y.z, < x.(y+1).0)
- 无前缀 = 精确版本 (如 prettier@3.5.3)

### 更新依赖
npm update              # 更新所有依赖到最新次版本
npm update package-name # 更新特定包
npm outdated           # 查看哪些包有新版本可用
npm audit              # 检查安全漏洞

### 安装特定版本
npm install package-name@1.2.3   # 安装精确版本
npm install package-name@latest  # 安装最新版本

## 🚀 安装和初始化流程

### 1. 首次安装
npm install             # 根据 package.json 安装所有依赖
                        # 生成 node_modules 和 package-lock.json
                        # 可用 yarn install (如果系统装了 yarn)

### 2. 初始化数据库 (只需一次)
npm run db:init         # 创建 SQLite 数据库和表结构

### 3. 启动开发环境 (两个终端)
终端 1 - 后端:
npm run server          # 启动 Express 服务器 (localhost:3000)

终端 2 - 前端:
npm run dev             # 启动 Vite 开发服务器 (localhost:5173)

### 4. 生产构建
npm run build           # 编译 Vue 前端到 dist/ (压缩、优化)
npm run preview         # 本地预览生产版本

## 🐳 Docker 环境下的包管理

Dockerfile 中的依赖安装:
- 前端构建阶段: npm ci  (使用 package-lock.json 确保版本一致)
- 最终运行阶段: npm ci --only=production (仅安装生产依赖)

### Docker 中的常用命令
docker-compose exec backend npm install   # 在容器中新增包
docker-compose exec backend npm run db:init  # 在容器中初始化数据库

## ⚠️ 常见包问题和解决

问题 1: node_modules 损坏
→ rm -rf node_modules package-lock.json
→ npm install

问题 2: sqlite3 安装失败
→ 需要 C++ 编译工具和 Python 3
→ Windows: Visual Studio Build Tools
→ macOS: Command Line Tools for Xcode
→ Linux: build-essential, python3-dev

问题 3: 端口被占用 (3000 或 5173)
→ npm run server -- --port 3001  (改不了)
→ 找到占用进程: lsof -i :3000 (macOS/Linux) 或 netstat -ano (Windows)
→ 关闭该进程

问题 4: 依赖版本冲突
→ npm ls package-name  (查看依赖树)
→ 清除缓存: npm cache clean --force

问题 5: npm 太慢
→ 换源: npm config set registry https://registry.npmmirror.com
→ 或用 yarn/pnpm
